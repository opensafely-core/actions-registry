# Actions Registry

> [!IMPORTANT]
> This project is no longer active and has been replaced by URL redirects from `actions.opensafely.org` to the [OpenSAFELY Actions GitHub organization](https://github.com/opensafely-actions).

Actions Registry was a simple Django website hosting information about reusable actions
for the OpenSAFELY framework.

It was deployed at [actions.opensafely.org](https://actions.opensafely.org).
